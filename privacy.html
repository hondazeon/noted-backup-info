プライバシー方針

記載日：2026年10月23日

Noted Backup は所有者本人のみが使用する個人用アプリです。バックアップ自動化は未導入のため、この方針は予定している構成と取り扱いを説明します。構成を変更する際は、記載も更新します。

1. 扱うデータと目的

所有者がバックアップ対象に指定したファイルを、復旧と世代管理のために処理します。Google Drive API は、アプリが作成するバックアップ用ファイルの作成、読み取り、更新、削除のために使用します。データを販売したり、広告配信や AI モデルの学習に利用したりしません。

2. アクセス権限と認証情報

所有者自身の OAuth デスクトップクライアントから、Google Drive の drive.file スコープのみを要求する予定です。このアプリの運用では、アプリ自身が作成するバックアップ用ファイルだけを扱います。

OAuth トークンは Ubuntu VPS 上の非公開の rclone 設定に保存し、公開リポジトリやこのサイトには含めません。restic の暗号化用秘密情報も非公開で管理し、復旧に必要な情報は別途安全に保管する予定です。

3. 保存と外部サービス

restic で暗号化したバックアップを、rclone を通じて所有者の Google Drive に保存する予定です。元データの処理は所有者が管理する VPS 上で行います。Google は Drive の保存・API 提供に関わり、VPS の提供事業者は実行環境の提供に関わります。各サービスによる処理には、それぞれの規約とプライバシー方針が適用されます。

この説明サイトは GitHub Pages で配信します。GitHub がサイト配信に伴うアクセス情報を処理する場合があります。サイト自体には分析ツール、広告、入力フォーム、独自の追跡用 Cookie を設置しません。これはホスティング事業者による処理がないことを意味しません。

4. 保持と削除

保持する世代数や期間は運用設定により決まります。現時点では固定の保存期間や削除期限を約束しません。所有者はバックアップ処理を停止し、Google Drive 上のバックアップと、VPS 上の関連データ・設定・トークンを削除できます。必要な復旧データを失わないよう確認してから削除します。

Google アカウントの設定からアプリのアクセスを取り消すこともできます。ただし、アクセスの取り消しだけでは、既存の Drive バックアップや VPS の設定は自動削除されません。削除は別途行う必要があります。

5. お問い合わせ

一般向けのサポート窓口やアカウント登録は提供していません。公開ページの記載への一般的な指摘は、公開リポジトリの Issues にお寄せください。Issues は誰でも閲覧できる公開の場です。ファイルの内容、個人情報、トークン、パスワードなどの非公開情報は送信しないでください。
